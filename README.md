# internet-speed-test-cli

Консольный скрипт на Node.js для замера скорости скачивания. Без внешних зависимостей.

## Что делает

1. Принимает адрес (лучше — тяжёлая картинка или файл).
2. Делает к нему 10 запросов **последовательно**, каждый раз дожидаясь полной загрузки тела ответа.
3. Считает среднее время запроса и общий объём скачанных данных.
4. Печатает скорость скачивания.

## Требования

Node.js 18 или новее (используется встроенный `fetch`).

## Запуск

```bash
node speedtest.js <url>
```

Пример:

```bash
node speedtest.js https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

Пример вывода:

```
#01: 8.12 МБ за 0.953 с
...
--- Результат ---
Среднее время запроса: 0.941 с
Скачано всего: 81.20 МБ
Скорость скачивания: 69.04 Мбит/с
```

## Единицы измерения

- Скорость — **мегабиты в секунду (Мбит/с)**, как в тарифах провайдеров. 1 Мбит/с = 1 000 000 бит/с; 1 байт = 8 бит.
- Объём данных — мегабайты (МБ), 1 МБ = 1 000 000 байт.
- Время — секунды.

## Как считается скорость

`скорость = (общий объём в байтах × 8) / суммарное время всех запросов / 1 000 000`

Это общий объём, делённый на общее время, а не среднее из скоростей отдельных запросов — так быстрые и медленные запросы учитываются пропорционально их размеру. Время каждого запроса измеряется от старта `fetch` до получения последнего байта тела.

## Обработка ошибок

Если адрес некорректен, сервер ответил не 2xx или сеть отвалилась, скрипт сообщает об ошибке и завершается с кодом 1.
